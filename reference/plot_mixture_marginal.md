# Plot marginal mixing distributions

This function plots an estimated marginal mixing distributions.

## Usage

``` r
plot_mixture_marginal(mean, cov, weights, name)
```

## Arguments

- mean:

  The class means.

- cov:

  The class covariances.

- weights:

  The class weights.

- name:

  The covariate name.

## Value

An object of class `ggplot`.
