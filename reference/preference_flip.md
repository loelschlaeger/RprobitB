# Check for flip in preferences after change in model scale.

This function checks if a change in the model scale flipped the
preferences.

## Usage

``` r
preference_flip(model_old, model_new)
```

## Arguments

- model_old, model_new:

  \[`RprobitB_fit`\]  
  Two models, one before and one after a scale change.

## Value

No return value, called for side-effects.
