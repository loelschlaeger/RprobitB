# Extract number of model parameters

This function extracts the number of model parameters of an
`RprobitB_fit` object.

## Usage

``` r
npar(object, ...)

# S3 method for class 'RprobitB_fit'
npar(object, ...)
```

## Arguments

- object:

  An object of class `RprobitB_fit`.

- ...:

  Optionally more objects of class `RprobitB_fit`.

## Value

Either a numeric value (if just one object is provided) or a numeric
vector.
